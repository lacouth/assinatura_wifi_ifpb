# Funcionamento

Nesta pasta esta contido os arquivo CSVs que armazenam os sinais dos reteadores de um determinado ambiente.

Estes arquiso CSVs são utilizados por um algoritmo chamado GeradorGraficoSinais.ipynb que transforma os dados em uma imagem.
esse algoritmo está armazenado na pasta experiments.

Essas imagens são armazenadas na pasta SignalChart.

Os dados desses arquivos são obtidos de um outro algoritmo chamado OrganizadorDeRedes.ipynb Que está armazenado na pasta experiments.
